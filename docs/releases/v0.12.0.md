for creating and revising general task and implementation plans in Codex.

## Current Requirements And Plan Revisions

A plan describes the currently agreed work. Removing or replacing an item
updates related goals, deliverables, steps, dependencies, acceptance criteria,
examples, and open questions. Canceled items leave the plan body without
becoming an unnecessary exclusion list. Effective constraints and unaffected
decisions remain intact. Real dependency conflicts require a focused
clarification; later user instructions may restore previously removed work.

The skill returns a complete revised plan by default and respects an explicitly
requested partial edit or change history. Specialized planning stays with its
existing owner. Planning authority follows the user's request and does not
independently grant execution, scheduling, or task creation.
