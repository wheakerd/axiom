# Axiom v0.18.0

Version `0.18.0` reworks `agents-architect`. The skill now treats its topology, document contracts, and field lists as defaults the model may depart from with a recorded reason, adds a memory model with three tiers and a flat registry for addressing, and moves task state out of the target repository's working tree. The startup routing gate, Hooks, and every manifest field other than the version are unchanged; the [runtime identity](../runtime-identity.md) owns the digest and policy revision.

## Decision Latitude

The [skill entry](../../plugin/skills/agents-architect/SKILL.md) separates its Always-On Rules, which stay invariant, from the shapes, counts, field lists, and byte targets in its references, which are now defaults. The model decides when repository evidence favors another shape and records the departure and its reason in the report. The ten-step routing algorithm became a short list of routing decisions; the document contracts keep an existing repository's established shape when it already routes reliably.

## Memory Tiers And Addressing

The new [memory-and-state reference](../../plugin/skills/agents-architect/references/memory-and-state.md) defines three tiers: durable rules in root `AGENTS.md` and routed `.agents/**` owners, a dated decision ledger at `.agents/decisions.md`, and task state. It lists growth signals, such as a registry beyond about twenty entries, two owners sharing the same signals, stale `last_verified` dates, repeated sibling scans, or contradictions, and a decision table whose options are consolidate, demote, archive, split by signal, expire, and re-route. Addressing uses one flat registry at `.agents/index.md` with stable slugs and applies-when signals; every owner is reachable in at most two hops, and group indexes appear only when the growth signals justify them.

## Task State Location

Earlier versions wrote session capsules to `.agents/.runtime/` and generated material to `.agents/.generated/` inside the target repository, where IDE indexers and code search read them. Task state now lives in the repository's Git metadata, resolved with `git rev-parse --path-format=absolute --git-path axiom/agents-architect/`, the same containment that `traceable-git-submit` uses for its baseline cache. The path is outside the working tree and `git status`, needs no `.gitignore` entry, and resolves correctly in a linked worktree. The capsule contract is defined once in the new reference; the runtime-and-updates and context-evidence references point at it. Leftover `.agents/.runtime/` and `.agents/.generated/` directories are migration candidates: delete obsolete capsules and move anything still needed. Personal rules stay in `.agents/local/`. Host user-level directories were evaluated and not selected: Claude Code documents only its auto memory directory as retained per project, and Codex documents no per-project state directory, so neither gives a host-neutral rule.
