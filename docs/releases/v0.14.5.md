# Axiom v0.14.5

Version `0.14.5` removes repeated capability descriptions from five `using-axiom` Bundled Routes entries: `clarify-intent`, `task-planning`, `agents-architect`, `optimize-codex-usage`, and `review-axiom-task`. Their unchanged skill frontmatter remains the matching source under the existing Route Once rule.

## Scope And Boundaries

Only those five list entries change. The rest of the startup gate, including its invocation notes, remains byte-identical to the preceding version. Delegation activation, continuous-progress explicit invocation, local web location checks, external-action authorization, combined release routing, ordinary Git exclusions, and reversible-change safeguards remain unchanged. No setting or user migration is required.

The context record compares the same fixed 95-case workload before and after using `static-contract-validation`, including 69 routed cases and 26 no-route controls. These results validate the checked-in contracts and corpus; they do not measure natural-language routing decisions or exact host token usage.
