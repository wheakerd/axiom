Version `0.8.13` is the patch release for [Issue #63](https://github.com/wheakerd/axiom/issues/63). It closes the transitive immutable-pin gap for local Docker actions without changing installed routes, hooks, Skills, authorization boundaries, or runtime dependencies.

## Digest-Pinned Local Docker Bases

The action-graph validator now reads the repository-owned `Dockerfile` for every referenced local Docker action. Each effective `FROM` must use `scratch`, a previously validated named stage, or a remote image pinned to `@sha256:<64 hex>`. Every build stage is checked, so one mutable intermediate source rejects the complete graph.

Digest-pinned remote sources, fixed literal platform selectors, case-insensitive `FROM` and `AS`, deterministic continuations, and later references to accepted stages remain valid. Tags, unpinned image names, variables or expressions, wrong digest algorithms or lengths, forward or duplicate stage names, malformed continuations, unsupported parser directives, alternate Dockerfile paths, and symbolic-link Dockerfiles fail closed. The parser uses only the Python standard library and never executes Docker or contacts a registry.

## Production-Owned Regression Contract

The canonical action-graph fixture set now contains 40 accepted and rejected scenarios, including one-stage `scratch`, digest-pinned remote sources, fully pinned multi-stage graphs, local stage reuse, casing and whitespace variants, every required mutable-source negative case, malformed or oversized image and stage names, split-instruction, heredoc, inline-hash continuation and escaped-escape bypasses, comment lines inside continuations, quoted and escaped comment boundaries, path escape, and Dockerfile symlink rejection. A focused socket-denial regression proves the fixture run remains offline.

The aggregate publication summary now reports `immutable external action and image pins`. It counts each full-SHA GitHub Action, digest-pinned `docker://` action, workflow job or service image, and digest-pinned remote Dockerfile `FROM` occurrence; `scratch` and validated local-stage references remain accepted without increasing the count.
