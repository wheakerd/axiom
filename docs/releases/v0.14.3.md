# Axiom v0.14.3

Version `0.14.3` refines the shared [skill notice contract](https://github.com/wheakerd/axiom/blob/v0.14.3/skills/using-axiom/references/skill-notices.md). Every direct skill entry already routes to that contract.

## Notice Format

Wrap the entire `Axiom:<skill-name>` marker in Markdown inline code, then add a brief invocation goal or reason on the same line. For example:

`Axiom:task-planning` Turn the current requirements into an actionable plan.

Continue further output in a new paragraph. Omit separator decorations between the marker and reason. This replaces the marker-only rule from `0.14.2`; invocation timing, route selection, consent, authorization, and repeat suppression remain unchanged.
