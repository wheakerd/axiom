# Axiom v0.27.2

Version `0.27.2` corrects the startup gate and the `agents-architect` description after an independent read-only review of the 0.27.0 tree, verified by the maintainer against the cited lines (Issue #261). The selection rules of the gate are unchanged; what changes is what the gate says about itself, which statements bind, which rules apply to every session, how a notice is spelled, and how large the gate is.

## Why A Patch

The [release standard](../runtime-identity.md#version-increment) assigns a patch increment to a fix without new capability: wording and reference corrections, narrowing of a wrongly scoped rule, and hardening. No route, trigger, or matching widens.

## What Changed

- Self-description. The gate selected bundled skills "and nothing else" while also binding a denial-is-a-stop rule, a pre-action sentence, and an output-language rule on every session. It now says that it selects bundled skills and states the session rules.
- Binding prohibitions. Invariant 2 said that only the listed invariants bind and everything else is an adaptable default; the skill readability contract caps invariants at six, so the secret-handling contract, the manifest rule, and every other prohibition outside an invariants list were defaults by the text's own definition. Invariant 2 now binds every prohibition a skill or its references state, and each bundled skill's invariants section names that exception. The readability contract's six-invariant cap and its rejection of blanket binding clauses are unchanged; a prohibition is a named rule, not a blanket clause.
- Session-wide rules. The Before Acting section is removed: `confirm-external-action`, `reversible-system-change`, and `traceable-git-submit` each require the exact action to be presented before it runs, and `references/host-permission.md` owns the denial boundary. The Output Language rule now applies to a turn in which a bundled route is selected, as the [Trust Model](../trust-model.md#authority-across-workflows) already stated.
- Notice spelling. `axiom:<skill-name>` replaces `Axiom:<skill-name>`, matching how Claude Code lists plugin skills and the lowercase kebab-case convention for plugin identifiers; the README, Getting Started, Examples, Architecture, the Trust Model, and the Simplified Chinese twins follow.
- Size and readability. The description drops "and local web research", which the body lost in 0.26.0; the terms list drops the envelope and write-set definitions that the owning skills carry; the credential paragraph points at its reference instead of restating it; two chained sentences become a short list of standing rules; the refresh rule joins that list. The gate shrinks from 7,363 to 6,843 UTF-8 bytes, about 520 bytes of new headroom below the 7,372-byte publication ceiling and the Codex default hook-output limit.
- `agents-architect` host boundary. The description states that the skill writes only `AGENTS.md` and that a Claude Code project with a `CLAUDE.md` does not load `AGENTS.md`, so there the skill stops and says so; [Compatibility](../compatibility.md) records the same boundary. Whether the skill should write `CLAUDE.md` natively is a separate product decision, not part of this release.

## Routing Contract

Routing contract v8 and both host benchmark profiles keep their 49 cases. The gate and one description changed. Repository policy revision 138 (Issue #267) removed the observation-record requirement, so this release carries no fresh-session observation record and no host session was run for it. The change has no routing purpose, so the two-arm same-batch measurement that decides gate reductions meant to change selection does not apply; the [routing-context record](../../evals/context-budget/results/v0.27.2.json) binds the reduction to equivalent static contract results before and after, kept distinct from the host-observed records.

## Unchanged Boundaries

The six invariants keep their numbering and meaning; routing still selects instructions only, a denial is still a stop, and no-match still continues host-native. No description other than `agents-architect` changes, and no selection condition widens.
