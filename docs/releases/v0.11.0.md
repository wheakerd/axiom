Candidate updated: 2026-09-15

Version `0.11.0` removes Axiom installation and runtime support for Claude Code.
Codex is the supported installation target. The `agent-plugin-architect` skill
still helps design Codex or Claude Code plugins for other projects.

## Runtime And Migration

The Claude plugin and marketplace descriptors and Claude SessionStart hook are
removed. Current installation, update and removal guidance now targets Codex.
Codex retains the shared Skills, marketplace, SessionStart hook and Windows
wrapper. Required user action: existing Claude Code users must disable or
uninstall their old Axiom installation in that host. Updating this repository
does not remove a cached installation. Use the [Codex installation guide](../guides/getting-started.md)
for a supported installation, then start a new session.

Runtime-contract schema v2 classifies the Codex package with 57 installed inputs.
It retains schema v1 and old observations as historical evidence. Its baseline
is derived from immutable v0.10.1 under v2; digests from different schemas are
not interchangeable. Repository policy revision 31 records this change.

## Release Verification

From this version, publication uses required repository checks, regression
tests, signed commits, protected tags and immutable artifact verification.
The Release carries an exact policy record and an integrity attestation.
Frozen no-Hook experiments replay their original v0.10.1 inputs; their original
protocols, results and outcomes remain historical evidence. See
[release verification](../maintainers/release-documentation.md#release-verification)
for the current publication contract.

## Exact Draft Evidence Validation
