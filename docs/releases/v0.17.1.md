# Axiom v0.17.1

Version `0.17.1` limits `agent-plugin-architect` to packaged plugin
architecture. Its description now covers a plugin's architecture across
shared Skills, route ownership, manifests, marketplace wrappers, hooks, and
version-bound compatibility evidence, and it no longer covers evaluating or
reviewing an individual Skill or Skill proposal. The startup routing gate,
Hooks, and manifest fields are unchanged; the
[runtime identity](../runtime-identity.md) owns the digest and policy revision.

## Routing Boundary

The earlier description offered to evaluate a packaged plugin's shared Skills.
Every bundled Axiom Skill is a shared Skill of a packaged plugin, so that
wording also matched a request to evaluate one proposed Skill, such as the
no-route control "Evaluate the proposed continuous-progress skill." The
[route contract](../agent-plugin-architect-route-contract.md) now lists that
request with ordinary host-native work. Package inventory, shared Skill trees,
route ownership, wrappers, hooks, release readiness, and compatibility evidence
still select the route; repository-local AGENTS systems and ordinary plugin
code remain outside it. The
[packaged Skill](../../plugin/skills/agent-plugin-architect/SKILL.md) keeps its
workflow and references.

## Publisher Catalog Sources

The publisher's job summary now renders each catalog's own source for the
verified Latest release: a `git-subdir` source with `path` `./plugin` for the
[Codex catalog](../../.agents/plugins/marketplace.json) and `plugin` for the
[Claude Code catalog](../../.claude-plugin/marketplace.json). The `v0.17.0`
publisher still rendered the earlier shared `url` object, and that release's
catalogs followed the documented layout instead. The renderer and the catalog
validators now share one source rule, as the
[release guide](../maintainers/release-documentation.md#marketplace-publication)
describes.

## Evidence Boundary

This local version note claims no publication or installed-host observation.
The [release status](../../evidence/release-status.json) keeps pending immutable
binding and unobserved Codex and Claude Code host fields. The startup gate is
unchanged from `0.17.0`; the fixed routing corpus remains unchanged, and this
version records no reduction experiment. Counts below are static proxies, not
billed tokens or observed lifecycle behavior.

## Exact Draft Evidence Validation

Any later draft follows the separately authorized
[release verification contract](../maintainers/release-documentation.md#release-verification).
Its Release body is rendered from the exact tagged Changelog entry.
