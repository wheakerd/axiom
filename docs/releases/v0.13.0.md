## Request Clarification

Materially different plausible meanings receive one focused question with
useful choices and space for a custom answer. Tentative wording alone is not
a trigger. Already-settled choices and facts obtainable from current context
do not require another question. Dependent work waits for a material decision;
authorized independent work can continue.

## Model-Aware Delegation

The main session model stays unchanged. The user supplies exact candidate
model IDs in priority order, and the main session selects the first supported,
sufficient candidate for a clear, bounded task. Suitability requires evidence;
model names do not establish capability or cost rankings.

Verified Full Access allows automatic assignment within existing authority
after announcing the exact child model and faithful task brief. Outside that
condition, existing explicit or standing assignment authority applies, or the
main session asks for confirmation. Missing preferences, an unlisted candidate,
expanded scope or disclosure, and action-specific boundaries remain decisions
for the appropriate owner. A user's instruction to always confirm still applies.

The delegation skill never directly invokes the clarification skill. Only
`using-axiom` may independently select clarification for unresolved user intent.
Unavailable or inefficient delegation continues in the main session. The main
session reviews and verifies the child result before claiming completion.

## Retired Validator

Version 0.13.0 deprecates and removes Axiom's use of the obsolete
`plugin-creator` allowlist validator. That implementation rejects supported
`hooks`, `interface.brandColorDark`, and `interface.supportURL` fields and is
excluded from required checks, optional diagnostics, and fallback validation.

Contributors must remove calls to that validator from their Axiom workflows
and use `python3 scripts/check-publication.py` for current package validation.
Use the host's equivalent Python 3 launcher when needed. The aggregate retains
strict manifest, value, path, asset, hook, and runtime-identity checks; bounded
native parsing remains a separate optional check. No replacement dependency
needs to be installed.

Earlier validator results remain in their original historical records. They
are not open failures of this version. The script was supplied by the host and
was never part of Axiom's package; this change removes its active integration.
Future retirements follow the
[release deprecation contract](../maintainers/release-documentation.md#deprecation-and-removal).
