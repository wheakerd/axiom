# Axiom v0.8.2

Released: 2026-08-23

Version `0.8.2` is a compatible patch for the Stage 3 routing defect tracked by
[Issue #34](https://github.com/wheakerd/axiom/issues/34). It clarifies that
publishing an already-prepared artifact selects only
`confirm-external-action`; publication alone is not a persistent system
change. A distinct installation, deployment, migration, activation, or
retention change still selects `reversible-system-change`, including dual
routing when it independently carries an external effect.

Both manifests advance together to `0.8.2`. Route names, descriptions, order,
authorization, hooks, marketplace wrappers, corpus, benchmarks, and historical
observations remain unchanged. This checked-in candidate creates no tag,
Release, pull request, Issue mutation, asset upload, or other remote action.
