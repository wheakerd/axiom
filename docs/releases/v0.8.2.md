# Axiom v0.8.2

Status: unreleased repair candidate

Version `0.8.2` is a compatible patch for the Stage 3 routing defect tracked by
[Issue #34](https://github.com/wheakerd/axiom/issues/34). It clarifies that
publishing an already-prepared artifact selects only
`confirm-external-action`; publication alone is not a persistent system
change. A distinct installation, deployment, migration, activation, or
retention change still selects `reversible-system-change`, including dual
routing when it independently carries an external effect.

Both manifests are synchronized at `0.8.2`. Route names, descriptions, order,
authorization, hooks, marketplace wrappers, corpus, benchmarks, and historical
observations remain unchanged. This checked-in candidate creates no tag,
Release, pull request, Issue mutation, asset upload, or other remote action.

## Observer Repair

The versioned [Codex exec JSONL taxonomy](../../evals/codex-exec-jsonl-observer-v2.json)
binds the closed eight top-level and nine item discriminators emitted by Codex
CLI `0.149.1` to exact official `openai/codex` source. The existing routing
validator classifies each item before lifecycle sequencing. Known benign items
may occur after `thread.started` and before `turn.started`; tool/action and
error items are counted and terminate even in that position. Unknown,
malformed, invalid-status, pre-thread benign, duplicate-phase, post-terminal,
and abrupt streams fail closed.

The classifier is standard-library validation code, not a model runner. Its
sanitized journal permits only public discriminators, fixed categories and
roles, enumerated statuses, and ordinals. It never retains response or
reasoning text, identifiers, tool arguments or output, credentials, paths,
session/config content, or raw payload. The prior terminal outcomes remain
unchanged because their destroyed private subtypes cannot be reconstructed.
