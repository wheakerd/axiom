Version `0.8.9` is the patch release for [Issue #59](https://github.com/wheakerd/axiom/issues/59). It makes authorization, rollback, and cleanup evidence fail closed unless every owned field contains the exact boolean singleton `True`.

## Strict Boolean Evidence

`axiom_validation.git_contracts.all_evidence()` now accepts `Mapping[str, Any]` evidence and a `Sequence[str]` field list, and evaluates each owned field with `value is True`. It does not coerce integers, strings, collections, nulls, or other values into authorization evidence.

`external_action_gate()` continues to delegate to the shared helper, and `rollback_gate()` now uses the same helper instead of maintaining a second truthiness implementation. Required field sets, mutation authority, and unknown-field behavior are unchanged: extra fields are ignored, but they cannot replace a missing owned field.

## Type-Confusion Regression Coverage

For every external-action, rollback, and cleanup-authority field, the shared regression matrix rejects `False`, `None`, `0`, `1`, `"false"`, `"true"`, an empty string, a non-empty string, an empty list, a non-empty list, an empty object, and a non-empty object. It also deletes every owned field in turn, repeats each missing-field case with an unknown truthy field, and confirms that complete exact-`True` evidence passes.

The aggregate reports 155 external-action gate fixtures, 127 rollback gate fixtures, and 238 traceable-Git contract fixtures including strict cleanup-authority coverage.
