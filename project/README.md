# Project Operations

This tree contains Axiom's public project-operation material. It is not current
product guidance, an installed capability, or authority to perform an external
action. Use [`docs/README.md`](../docs/README.md) for user and maintainer
documentation.

Status claims in this collection are time-bounded snapshots. The source
documents retain their absolute verification dates and distinguish planned,
submitted, pending, published, completed, not-run, and not-verified states.
Moving a document here does not revalidate its claim or execute its plan.
